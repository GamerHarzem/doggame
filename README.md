# Dog Brawlers

Brawl Stars tarzı lobi arayüzü ve basit 3v3 "Gem Grab" oyunu. Tamamen statik dosyalardan oluşur, derleme gerekmez.

## Dosyalar
- `index.html` – lobi ekranı ve oyun ekranı
- `style.css` – arayüz stilleri
- `game.js` – oyun mantığı (3v3, botlar, joystick/klavye)

## Kontroller
- Masaüstü: WASD hareket, sol tık saldırı, Boşluk yetenek (dash, 5 sn bekleme)
- Mobil: joystick, 🦴 saldırı, ⚡ yetenek

## Kurallar
15 gem'e ilk ulaşan takım ya da 2 dakika sonunda önde olan takım kazanır.

## GitHub Pages
Repo ayarlarında Settings → Pages → Branch: `main` / root seçin.
